# 🌍 Country Explorer App

A modern React application that displays detailed information about countries using the REST Countries API.

Built with React, Bootstrap, and Styled-Components, featuring skeleton loaders and smooth UI transitions for a professional user experience.

---

## 🚀 Features

- 🌎 View all countries
- 🔍 Search countries by name
- 🌍 Filter by region
- 📄 Detailed country information page
- ⬅ Back navigation button
- 💀 Skeleton loaders (shimmer effect)
- 🌗 Dark mode support
- 🎨 Smooth fade-in animations
- 📱 Fully responsive design

---

## 🛠 Tech Stack

- React.js
- React Router DOM
- Bootstrap 5
- Styled-Components
- REST Countries API

---

## 📡 API Used

Data is fetched from:

https://restcountries.com/v3.1/all?fields=name,flags,population,region,capital,cca3,currencies
