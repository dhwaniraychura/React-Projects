🔐 AuthApp
A modern, full-featured React authentication application built with Firebase and Material UI. Features a luxury dark-themed UI with gold accents, complete auth flows, and a clean dashboard experience.

✨ Features

📧 Email & Password — Register, login, and reset password
🔑 Google OAuth — One-click sign-in with Google
👤 Profile Management — Update display name and photo URL
🔒 Password Change — Secure in-app password update
📬 Forgot Password — Firebase email reset flow
🛡️ Protected Routes — Dashboard and Profile require authentication
🎨 Luxury Dark UI — Deep black + gold theme with Playfair Display typography


🛠️ Tech Stack
LayerTechnologyFrontendReact 18UI LibraryMaterial UI (MUI) v5AuthenticationFirebase AuthRoutingReact Router v6IconsMUI Icons / Google IconsFontsPlayfair Display, DM Sans (Google Fonts)
